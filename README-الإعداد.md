# لوحة العقارات — خطوات الإعداد

كل الخطوات مجانية ضمن حدود Cloudflare المجانية.

---

## ١. أنشئ قاعدة البيانات

من لوحة Cloudflare: **Storage & Databases** ← **D1** ← **Create database**

الاسم: `wajha-properties`

بعد الإنشاء انسخ **Database ID** والصقه في `wrangler.toml` مكان `ضع-المعرّف-هنا`.

ثم نفّذ ملف الجداول — من تبويب **Console** داخل القاعدة، الصق محتوى `schema.sql` واضغط تنفيذ.

---

## ٢. أنشئ مخزن الصور

**R2 Object Storage** ← **Create bucket**

الاسم: `wajha-property-images`

اتركه **خاصاً** — الصور تُقدَّم عبر مسار `/r/` من الموقع نفسه، لا حاجة لفتح المخزن للعامة.

---

## ٣. اربط الاثنين بالموقع

**Workers & Pages** ← مشروعك ← **Settings** ← **Bindings**

| النوع | الاسم | القيمة |
| --- | --- | --- |
| D1 database | `DB` | `wajha-properties` |
| R2 bucket | `BUCKET` | `wajha-property-images` |

الاسمان `DB` و `BUCKET` هما ما يستخدمه الكود — لا تغيّرهما.

---

## ٤. احمِ لوحة التحكم

**Zero Trust** ← **Access** ← **Applications** ← **Add an application** ← **Self-hosted**

| الحقل | القيمة |
| --- | --- |
| Application name | لوحة العقارات |
| Domain | نطاقك |
| Path | `admin` |

أضف تطبيقاً ثانياً بنفس الإعدادات للمسار `api` — وإلا بقيت نقاط الكتابة مكشوفة.

**السياسة:** Action = Allow، القاعدة = **Emails**، وأضف البُرد الثلاثة.

طريقة الدخول: **One-time PIN** — رمز يصل البريد، بلا كلمة سر.

> الكود يرفض أي طلب لا يحمل ترويسة Access. فلو نُشر بدون هذه الخطوة، لن تُفتح اللوحة للعامة بل ستتوقف — وهذا مقصود.

---

## ٥. حدّث سياسة الأمان

لوحة التحكم تحتوي كوداً داخلياً ببصمة مختلفة عن بصمات صفحات الموقع، وتحتاج الاتصال بالـAPI.

أضف هذا إلى ملف `_headers` **قبل** القاعدة العامة `/*`:

```
/admin/*
  Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; connect-src 'self'; frame-ancestors 'none'
  X-Robots-Tag: noindex, nofollow
```

وفي القاعدة العامة `/*`، أضف `blob:` إلى `img-src` ليعمل معاينة الصور قبل الرفع.

---

## ٦. ارفع الملفات

انسخ المجلدات إلى جذر المستودع:

```
functions/        ← نقاط الـAPI
admin/            ← لوحة التحكم
schema.sql
wrangler.toml
```

ثم ارفع على GitHub. Cloudflare Pages ينشر تلقائياً.

---

## ٧. جرّب

افتح `نطاقك/admin` — يطلب بريدك، يصلك رمز، تدخل.

أضف عقاراً، احفظ، ارفع صوراً، فعّل **منشور**.

**اختبار مهم:** افتح `نطاقك/admin` من متصفح خفي بلا تسجيل دخول — يجب أن يُمنع الدخول.

---

## ملاحظات

**الصور** تُصغَّر داخل متصفحك قبل الرفع إلى ١٦٠٠ بكسل. لا تجهّزها مسبقاً — ارفعها كما هي من الجوال.

**الأرقام المرجعية** تُولَّد تلقائياً: `WJ-001` وما بعدها. تظهر للزائر وتُرسل مع رسالة الواتساب ليعرف عن أي عقار يسأل.

**المباع** يختفي عن الزوار تلقائياً مع بقاء بياناته وصوره. لا تحذف عقاراً بيع — غيّر حالته فقط، فالسجل مفيد لاحقاً.

**السعر** يُحفظ دائماً ويظهر فقط لمن فعّلت له «أظهر السعر». الافتراضي مطفأ.

**حدود الخطة المجانية:** ١٠ غيغابايت في R2 و٥ غيغابايت في D1 — تكفي آلاف الصور. القراءات مجانية ضمن حدود واسعة.
